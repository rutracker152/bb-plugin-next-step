# Проверка подготовки версии 0.1.0

Дата: 2026-11-13.

## Среда

- Linux, Node.js 22.22.3, npm 10.9.8.
- BB 0.49.0, Plugin SDK 0.6.132.
- Пакет `bb-plugin-next-step`, идентификатор BB `next-step`, версия `0.1.0`.
- Лицензия MIT, автор `rutracker152`.

## Результаты

Команда `npm run check:clean` завершилась с `CLEAN_INSTALL_PASSED`.

1. Создана новая копия исходников без `node_modules` и `dist`.
2. Выполнено `npm ci --omit=dev --omit=optional --ignore-scripts`: установлена только production-зависимость Zod. Plugin SDK в этой копии отсутствовал.
3. `bb plugin build .` собрал сервер, интерфейс и host-часть. Идентификатор и версия в метаданных всех трёх сборок совпали с манифестом.
4. Во второй чистой копии выполнено `npm ci --include=dev`, затем `npm run typecheck` и `npm test`. Проверка типов и все 19 тестов прошли.
5. Запущен отдельный BB с пустой папкой данных и собственными локальными портами. Перед установкой подтверждено, что CLI обращается именно к этому экземпляру.
6. В нём выполнена установка production-копии через `bb plugin install`. Плагин получил статус `running`; совместимость интерфейса подтверждена BB.
7. Команда `bb next-step status --json` вернула `{"enabled":true,"activeRequests":0}`. Отключение и включение настройки проверены повторным чтением состояния.
8. Временный BB остановлен, его данные удалены. Исходный путь рабочей установки плагина сохранён.

Дополнительно проверены идентификатор пакета, совпадение лицензии в манифесте и lock-файле, состав `npm pack --dry-run` и отсутствие известных шаблонов приватных ключей, токенов, личной почты и локальных путей в исходниках для публикации.

Это проверка локальной установки пакета. Установка с публичного GitHub-адреса проверяется после создания репозитория и выпуска релиза.

## Повторение

```sh
npm ci --include=dev
npm run check:clean
```

Нужны доступные в PATH `bb`, `bb-app`, Node.js и npm. JSON-отчёт последнего запуска сохраняется в `test-results/clean-install.json`; эта папка исключена из Git.
